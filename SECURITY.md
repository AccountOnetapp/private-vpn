# Security policy

Do not open a public issue containing a subscription URL, gateway address,
private key, provisioning profile, or exploit details. Contact the repository
owner privately through the GitHub profile until a dedicated security address
is published.

The current `0.1.x` line is a development client. It intentionally fails closed
on physical devices because the packet transport core has not been linked or
audited. Only the latest commit on `main` is supported.
