# Handoff: runnable cross-platform client MVP

- **Author / task:** Codex; create a cross-platform VPN client in the user's
  `Applications iOS` folder, using Flutter while keeping iOS runnable in Xcode.
- **Result:** Flutter targets for iOS, Android, macOS, Windows, and Linux;
  subscription activation; platform-secure storage; native method-channel
  boundary; iOS `NETunnelProviderManager` and Packet Tunnel extension; Android
  bridge; simulator demo; unit tests; Xcode workspace.
- **Branch and commits:** `main`; commit hash will be added after verification.
- **Checks:** `dart format`, `flutter analyze` and `flutter test` from an
  ASCII-path copy because of a Flutter 3.47.8 analyzer bug with the requested
  Cyrillic path; `flutter build ios --simulator --debug`; successful install
  and launch on an iPhone 16 Pro simulator; repository diff and secret scan.
- **Published:** not yet at the time of this handoff draft.
- **Limitations:** the packet transport core is deliberately not linked; a real
  device build also requires Apple Network Extension provisioning. Android and
  desktop native tunnel adapters are not implemented. No claim of a working
  production VPN is made.
- **Next steps:** select and integrate the transport core, connect Remnawave
  subscription parsing, test on a provisioned iPhone, implement Android
  `VpnService`, then add failover and split routing.
